Optional: prepare a passage with another chatbot

The built-in model works locally. If you use a cloud chatbot, that is an upload to its provider and needs permission. A separately installed local chatbot can work offline. Copy the prompt, then paste its proposed text into Prepared passage above and review it.

Project backups contain the complete original, proposed text, note destinations, and review decisions. Store them appropriately. A listening edition does not change the source book's rights.


Listen and save
Use a short preview first. The included English voice uses public-domain LJ Speech recordings. Text preparation is multilingual; this initial narration voice is English.
Start chapter headings with “# ” in the prepared text. Notes are placed in their own final chapter. Export limit: 300,000 UTF-8 text bytes and 768 MiB of WAV audio per job. For longer books, save multiple parts. MP3/M4B use a locally installed FFmpeg; the WAV option is included.
