Browser models and offline setup

This edition runs on your device. Download the narration voice (about 40 MB) and, for AI preparation, a WebGPU text model (hundreds of MB to over 1 GB). Download providers receive asset requests, not your text. Browser storage can be evicted; keep project backups.

Checking browser support…

AI requires WebGPU and enough GPU memory. Narration uses CPU WebAssembly. Model files persist only after you request them; manuscripts stay in memory until you explicitly save a backup. Removing shared matching model assets may require another page on this origin to download them again. Browser audio is capped at 96 MiB per job; long books should be saved in parts. The downloadable app supports larger jobs and optional MP3/M4B.

Optional: prepare a passage with another chatbot

The built-in model works locally. If you use a cloud chatbot, that is an upload to its provider and needs permission. A separately installed local chatbot can work offline. Copy the prompt, then paste its proposed text into Prepared passage above and review it.

Project backups contain the complete original, proposed text, note destinations, and review decisions. Store them appropriately. A listening edition does not change the source book's rights.


Listen and save
Use a short preview first. The included English voice uses public-domain LJ Speech recordings. Text preparation is multilingual; this initial narration voice is English. The browser edition exports WAV chapters.
Start chapter headings with “# ” in the prepared text. Notes are placed in their own final chapter. Browser export limit: 100,000 UTF-8 text bytes and 96 MiB of WAV audio per job. For longer books, save multiple parts. MP3/M4B use a locally installed FFmpeg; the WAV option is included.
